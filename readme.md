# 슈엔노트

- 개요

1. 가챠시뮬 (nikkehub.com의 가챠시뮬과 비슷한 방향으로 설계)
2. 테마색은 보라색
3. blablalink를 통한 내 정보 불러오기
4. 전체 플레이어블 니케 정보 제공
5. 니케 이름맞추기 퀴즈 추가

## 결정 사항

### 기술 스택
- Next.js (API 라우트로 blablalink 프록시 처리)
- Supabase (Postgres + 인증)
- 로그인: 디스코드 OAuth
- 배포: Vercel 공개 배포
- 반응형: PC와 모바일 동등하게 지원

### 데이터
- 니케 캐릭터 데이터와 이미지는 blablalink에서 수집
- blablalink 연동 방식(내 정보 불러오기)은 조사 후 결정
- 공개 배포이므로 blablalink 이용약관과 에셋 저작권 확인 필요

### 가챠 시뮬
- 일반/픽업 모집 확률 반영, 1회/10회 뽑기
- 뽑기 연출 (카드 뒤집기, 등급별 효과)
- 통계/기록 (누적 횟수, SSR 획득 기록, 소모 재화)
- 마일리지/천장
- 기록은 회원 계정(Supabase)에 저장

### 이름 맞추기 퀴즈
- 문제 유형: 실루엣 보고 맞추기, 일러스트 보고 맞추기
- 난이도: 쉬움 = 객관식 4지선다, 어려움 = 직접 입력(자동완성)
- 기록은 회원 계정에 저장

## 진행 순서
1. 프로젝트 세팅 + 보라 테마 + blablalink 조사
2. 니케 도감
3. 가챠 시뮬
4. 이름 맞추기 퀴즈
